# TeamHub 운영 안내

기능이 아니라 **운영**에 관한 문서. 인사관리실(관리자)이 읽는다.
한 번 설정하면 끝나는 것과 매달 하는 것, 그리고 무료 플랜이라 알고 있어야 하는 제약을 모았다.

---

## 1. 매달 하는 것 — 백업 (10분)

Supabase 무료 플랜에는 **우리가 되돌릴 수 있는 백업이 없다.** 한 달에 한 번 직접 뜬다.

```bash
SUPABASE_DB_URL='postgresql://postgres:비밀번호@db.xxxx.supabase.co:5432/postgres' \
  bash scripts/backup.sh
```

- 연결 문자열: Supabase 대시보드 → **Project Settings → Database → Connection string → URI**
  (Connection pooling 은 끄고 Direct connection 을 쓴다)
- 결과 파일 `backups/teamhub-YYYY-MM-DD.sql.gz` 를 **사내 드라이브에 올린다.**
  PC 안에만 두면 백업이 아니다. 3개월치만 남기고 지워도 된다.
- **첨부 파일은 이 덤프에 안 들어간다.** 대시보드 → Storage → `attachments` 에서
  중요한 것만 따로 내려받거나, 애초에 큰 자료는 사내 드라이브 링크로 공유한다.

> 본문 실수는 백업까지 안 가도 된다. 페이지 ⋯ 메뉴 → **본문 기록 · 되돌리기** 로
> 최근 30개 버전(90일) 안에서 복구할 수 있다. 백업은 "프로젝트 전체가 날아갔을 때" 용이다.

## 2. 한 번만 하면 되는 것 — 비밀번호 찾기 열기

지금은 비밀번호를 잊으면 **관리자만** 초기화할 수 있다(관리자 화면 → 비번 초기화).
25명이면 한 달에 한두 건인데, 관리자가 자리에 없으면 그 사람은 일을 못 한다.

회사 메일 서버(네이버웍스 메일 등)를 붙이면 본인이 스스로 재설정할 수 있다. **무료다.**

1. Supabase 대시보드 → **Project Settings → Authentication → SMTP Settings**
2. `Enable Custom SMTP` 켜고 회사 메일 정보 입력
   - Host / Port: 네이버웍스 SMTP (`smtp.worksmobile.com`, 465 또는 587)
   - Username / Password: 발송 전용 계정 (개인 계정 말고 `teamhub@회사도메인` 같은 것을 하나 파는 게 좋다)
   - Sender email / Sender name: 위 계정 / `TeamHub`
3. **Authentication → Email Templates → Reset Password** 의 문구를 한국어로 다듬는다
4. 로그인 화면에 "비밀번호 찾기" 를 넣는 작업은 그다음에 하면 된다 (설정이 먼저)

> Supabase 기본 메일 발송은 시간당 몇 건으로 제한돼 있어 실제로는 못 쓴다.
> 반드시 회사 SMTP 를 연결한 뒤에 열어야 한다.

## 3. 켜고 싶을 때 — 네이버웍스 알림

앱 안의 🔔 만으로는 **앱을 안 여는 사람에게 닿지 않는다.** 정착에 가장 크게 기여할 항목.
Edge Function 코드는 이미 들어 있고, 꺼져 있을 뿐이다.

설정 절차는 [`supabase/functions/push-notifications/README.md`](../supabase/functions/push-notifications/README.md) 에 있다.
요약하면: 네이버웍스 Developer Console 에서 봇을 만들고 → `supabase functions deploy` →
`supabase secrets set` → pg_cron 으로 1분마다 호출.

각 사람의 네이버웍스 ID 를 `profiles.naverworks_id` 에 넣어야 DM 이 간다.

## 5. 사람이 들어오고 나갈 때

**입사**
1. 관리자 화면 → 멤버 추가 (이름·이메일·소속·직급·직책) → 임시 비밀번호가 나온다
2. 임시 비밀번호를 전달 → 첫 로그인 때 본인이 바꾼다 (강제)
3. 그 사람이 홈에 처음 들어가면 **시작 안내 + 📖 팀허브 3분 사용법** 이 뜬다

**퇴사·휴직**
1. 관리자 화면 → 해당 멤버 → **비활성화**
2. 담당 업무가 남아 있으면 **누구에게 넘길지 묻는 창**이 뜬다 → 후임을 고르면 한 번에 옮기고
   각 업무의 진행 기록에도 인수인계 내역이 남는다
3. 계정 행은 지우지 않는다 — 과거 회의록의 멘션과 진행 기록이 깨지지 않도록

**조직 개편**
- 관리자 화면 → 조직도 관리에서 실·팀을 고친다
- 공간별 작성 권한(전원 / 리더 / 지정)도 여기서 정한다. 공용 공간은 기본이 "전원"

## 6. 정착시키는 법 (기능보다 중요)

기능은 충분하다. 두 달 뒤에 실패한다면 이유는 기능이 아니라 "왜 여기다 쓰지?" 다.

1. **회의록만 먼저 강제한다.** "본부 회의록은 여기에만" — 규칙 하나면 된다.
   회의록에 액션 아이템이 붙고, 그게 업무가 되고, 업무가 진행 로그를 부른다.
2. **주간회의를 `주간 모아보기` 화면을 띄워 놓고 진행한다.**
   화면이 회의 도구가 되면 사람들이 그 전날 로그를 쓴다. `주간 정리 초안 만들기` 버튼으로
   회의록 초안까지 한 번에 만든다.
3. **3주는 인사관리실만 파일럿** → 불편한 점을 모아 고친 뒤 본부 전체 오픈.
