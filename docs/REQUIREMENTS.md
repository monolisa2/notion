# TeamHub 요구사항 정의서 v1 (초안)

작성 2026-09-18 · 상태: **v1 확정** (2026-09-18 결정사항 반영)

---

## 1. 한 줄 정의

> 본부 30명(4팀)이 **업무 진행 상황을 공유하고, 회의록·자료·공지를 한곳에 모아 두는**
> 노션형 내부 플랫폼. 비용 0원(Vercel·Supabase·GitHub 무료 플랜), 우리가 직접 고칠 수 있는 것.

노션을 쓰지 않는 이유는 단 하나: **우리 방식대로 고칠 수 없다.** 그래서 노션의 좋은 점(페이지 중첩, 표·보드·캘린더 뷰, 댓글·멘션)은 그대로 가져오고, 우리에게 필요 없는 것(외부 공유, 무제한 속성 커스터마이징, AI)은 뺀다.

## 2. 노션은 무엇을 하는 도구인가 (조사 요약)

노션의 뼈대는 네 가지다. 우리는 이 네 가지를 "고정된 형태"로 구현한다.

| 노션 개념 | 노션에서 | TeamHub 에서 |
|---|---|---|
| **페이지 + 블록** | 문단·제목·표·이미지 등 모든 것이 블록. 페이지 안에 페이지 무한 중첩 | 그대로. 에디터는 BlockNote(노션형 오픈소스)로 해결. 이미 구현됨 |
| **데이터베이스 + 뷰** | 표 하나를 테이블/보드/캘린더/타임라인/갤러리로 바꿔 봄. 속성(담당자·상태·날짜·태그)을 자유롭게 추가 | 속성을 **미리 정해둔** "업무" 하나만 데이터베이스로 제공. 뷰는 테이블·칸반·캘린더 3종. 자유 속성 추가는 v1 범위 밖 |
| **팀스페이스 + 권한** | 팀별 공간(Open/Closed/Private), 멤버·게스트, 페이지 단위 공유 | **공간 5개 고정**: 본부 공용 + 팀 4개. 공간마다 "본부 전체 공개 / 팀만" 두 단계. 외부 게스트 없음 |
| **협업** | 댓글·@멘션·알림·실시간 공동편집 | 댓글·멘션·알림은 구현됨. 실시간 공동편집(커서 공유)은 안 함 — 자동저장 + "○○님이 수정 중" 표시로 대체 |

노션에 있지만 **v1 에서 뺄 것**: 실시간 공동편집, 자유 속성/수식/관계형 속성, 외부 공개 링크, AI 기능, 위키 검증, 데스크톱/모바일 앱(브라우저로 대체).

## 3. 사용자와 조직 (인사 시스템 조직도 2026-09-18 기준)

경영관리본부 25명. 구조는 **본부 > 실 > 팀** 3단계다.

```
경영관리본부 (25)
├─ 인사관리실 (7)            신민철 차장·팀장 / 김세연 박도영 박민희 박선영 박소영 박소윤
├─ 재무관리실 (13)
│   ├─ (실 직속)  정탁 부장·실장
│   ├─ 재무팀 (2)             유숙진 차장·팀장 / 김수연
│   ├─ 총무팀 (3)             권경호 차장·팀장 / 류강훈 변재훈
│   └─ 회계팀 (7)             유보람 과장·팀장 / 백상원 양선화 양환동 오효경 정현아 하태훈
└─ 행정관리실 (5)
    └─ 환경관리팀 (5)         강영목 김정환 김홍남 오영훈 이민지
```

- **공간(스페이스)** 은 이 조직도를 그대로 따른다: 본부 공용 + 실 3개 + 팀 4개. 사람은 소속 단위에 속하고,
  실장은 실 아래 팀들을 모두 본다. 조직도는 관리자가 화면에서 고칠 수 있어야 한다 (10월 합병 대비)
- 사람 정보: 이름, 직급(사원/주임/대리/과장/차장/부장), 직책(팀원/팀장/실장), 소속, 회사 이메일
- 역할 2단계: **관리자**(본부장·실장·팀장 + 인사팀 담당자) / **일반**
- **로그인: 회사 이메일 + 비밀번호.** 구글 계정은 쓰지 않는다.
  - 가입은 열어두지 않고 **관리자가 조직도 명단으로 계정을 만들어** 임시 비밀번호를 네이버웍스 메신저로 전달한다
  - 첫 로그인 때 비밀번호 변경을 강제한다. 비밀번호를 잊으면 관리자가 초기화한다
  - 이 방식이면 메일 발송 설정이 전혀 필요 없다. 나중에 원하면 네이버웍스 SMTP 를 붙여 "비밀번호 찾기" 메일을 열 수 있다

## 4. 무엇을 하는가 — 5가지 사용 장면

### 4-1. 업무 진행 상황 공유 (핵심)
- 업무는 "속성이 붙은 페이지": 상태(대기/진행/검토/완료/보류/드롭), 담당자, 진행률, 기한, 우선순위, 팀
- 팀별·담당자별로 **테이블 / 칸반 / 캘린더** 로 본다
- 업무 페이지 하단에 **진행 기록**(한 줄 + 진행률)을 남기면 상태가 따라 바뀐다 → "어떻게 여기까지 왔는지"가 남는다
- 본부 대시보드: 정체 업무, 막힌 업무, 기한 임박, 담당자별 현황, 활동 피드 (5개 고정)

### 4-2. 회의록
- "회의록" **템플릿**으로 새 페이지 생성 → 일시·참석자·안건·결정사항·액션아이템 틀이 채워져 있음
- 액션아이템은 클릭 한 번으로 **업무로 승격** (담당자·기한 붙음)
- 팀 공간 아래 "회의록" 폴더 페이지에 날짜순으로 쌓임

### 4-3. 자료 아카이브
- 페이지 안에 파일 첨부(이미지·PDF·오피스 문서). Supabase Storage 무료 1GB
- **업로드는 파일당 50MB 까지** (무료 플랜의 상한. 요청은 100MB 였으나 유료 플랜에서만 가능), 그 이상은 **링크 첨부**
- 전체 1GB 를 넘기지 않도록 관리자 화면에 사용량 표시
- 제목·본문 **전체 검색** (한글 형태소까지는 아니고 단어 단위)

### 4-4. 공지
- 관리자가 페이지를 **공지로 고정** → 홈 상단에 노출, 읽음 표시(누가 읽었는지 관리자만 확인)
- 별도 게시판을 만들지 않고 페이지의 속성으로 처리

### 4-5. 일정
- 업무 기한과 회의록 일시를 모아 보는 **월간 캘린더** (본부/팀 필터)
- 구글 캘린더 연동은 안 함 (비용·권한 복잡). 나중에 필요하면 검토
